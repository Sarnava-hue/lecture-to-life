# Lecture-to-Life

Lecture-to-Life is an AI-powered learning companion that transforms lectures, PDFs, and educational content into structured study material.

## Planned Features

- Lecture and PDF upload
- Audio transcription
- AI-generated summaries
- Flashcard generation
- Quiz generation
- Retrieval-Augmented Generation (RAG)
- AI-powered study tutor
- Learning progress tracking

## Project Structure

- `backend/` – FastAPI backend and AI processing pipeline
- `frontend/` – User interface
- `docs/` – Project documentation
- `uploads/` – Temporary uploaded files
- `scripts/` – Utility and setup scripts
